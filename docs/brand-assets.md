# Brand assets

APCc stands for **APC Control**. The visual identity uses charcoal, evergreen,
and pale lime to pair readable operational information with a calm interface.

- `assets/logo.svg`: original, editable vector power/control mark.
- `assets/wordmark.svg`: vector project identity and tagline.
- `assets/hero.png`: original presentation illustration generated with the built-in image generation tool.
- `assets/dashboard.png` and `assets/outlets.png`: application screenshots made entirely from synthetic fixtures.

The hero is conceptual artwork, not a photograph or specification of a particular UPS.
The project is independent and is not endorsed by APC or Schneider Electric.

## Illustration prompt

Use case: ads-marketing. Asset type: wide 16:9 GitHub project presentation artwork for APCc (APC Control), a local UPS administration tool. Create an elegant premium editorial 3D illustration of a generic black rackmount uninterruptible power supply as a precise industrial object, with a small restrained lime-green status light and abstract electrical pathways forming a calm geometric halo. Dark charcoal and deep evergreen background, pale lime accents, satin black metal, soft studio lighting, finely composed generous negative space. A trustworthy understated infrastructure-software aesthetic, no futuristic fantasy machinery. Include only the exact short wordmark 'APCc' in clean modern white typography with a smaller line 'APC CONTROL'; these must be spelled exactly. No other text, no numbers, no serial labels, no IP addresses, no company names or third-party logos, no people, no watermarks, no metrics or dashboard readouts. It should feel like a polished open-source project cover, not a specific commercial hardware model.
